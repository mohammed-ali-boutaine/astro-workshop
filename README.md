# Astro Workshop - Savory E-commerce Site

This is an **Astro workshop project** that demonstrates building a  and simple e-commerce website called "Savory" - a platform specializing in premium sandwich-making kits. The project showcases Astro's static site generation capabilities enhanced with **custom React/TSX components** for interactive functionality.

## Workshop Learning Objectives

🎯 **Astro Framework Mastery** - Learn Astro's islands architecture and static site generation  
⚛️ **React/TSX Integration** - Custom interactive components built with React and TypeScript  
🏗️ **Modern Web Architecture** - Combining static and dynamic content seamlessly  
� **State Management** - Implementing cart functionality with Nanostores  
🎨 **Component Architecture** - Building reusable Astro and React components  

## Project Features (Customized with React/TSX)

🥪 **Sandwich Kit Marketplace** - Product catalog with custom React components  
🛒 **Shopping Cart System** - Interactive cart built with React/TSX and Nanostores  
📱 **Responsive Design** - Mobile-first interface with Astro layouts  
📝 **Content-Rich Blog** - Markdown-based blog system using Astro Content Collections  
🎯 **Dynamic Product Listing** - API integration with React components for real-time data  

## Tech Stack & Customizations

- **Astro 5.x** - Static site generation with islands architecture
- **React 19 + TypeScript** - Custom interactive components (.tsx files)
- **Nanostores** - Lightweight state management for cart functionality
- **Content Collections** - Markdown-based blog system
- **Custom React Components** - AddToCartButton, Cart, NewsForm
- **RSS Feed** - Automated content syndication
- **API Integration** - Dynamic product fetching

## Workshop Highlights

This project demonstrates how to effectively combine Astro's performance benefits with React's interactivity, showcasing the best of both worlds in modern web development.
